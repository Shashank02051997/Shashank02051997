### 🌱 About

I run **ImliStack**, a founder-led software studio in India building for teams in the **US, UK, Canada, Europe, the Middle East and Australia**. When you work with us, you talk to the engineer designing and building your product, not an account manager.

```yaml
founder:      Shashank Singhal  # leads every engagement hands-on
experience:   8+ years across web, mobile and DevOps
delivered:    40+ projects for 20+ clients, MVPs to production platforms
open_source:  6,100+ GitHub stars on Android & Flutter libraries
promise:      written scope · working software every cycle · you own the code
```

### 🛠️ What we build

| | Service | Typical work |
|:-:|---|---|
| 🌐 | **Web apps & SaaS** | React, Next.js, Angular front ends on Node.js / NestJS APIs |
| 📱 | **Mobile apps** | Flutter for Android & iOS; native Kotlin/Java when the platform demands it |
| 🤖 | **AI agents & automation** | LLM features, chatbots, voice agents, document & approval workflows |
| 🏭 | **Manufacturing & ERP** | Inventory, production tracking, WMS; Tally, SAP, Zoho, QuickBooks, Sage integrations |
| ☁️ | **Cloud & DevOps** | AWS, Azure, DigitalOcean, Cloudflare; CI/CD, monitoring, backups |
| 🔧 | **Rescue & modernisation** | Stabilising legacy systems; taking Lovable/Bolt prototypes to production |
